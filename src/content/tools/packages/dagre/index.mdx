`@dagrejs/dagre` computes a layered layout for a directed graph: you give it
nodes with dimensions and a set of edges, it assigns each node an `x`/`y`. It
draws nothing and knows nothing about React or the DOM, which is exactly why it
pairs with a renderer such as
<a href="/docs/tools/packages/xyflow-react">@xyflow/react</a>.
